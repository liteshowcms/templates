# Liteshow Templates

Official site templates for Liteshow CMS.

## Available Templates

### astro
Full-featured Astro template with:
- Tailwind CSS styling
- Content blocks (Hero, CTA, Markdown, Features, Testimonials, FAQ)
- SEO optimization
- Custom favicon support
- Static site generation
- Works on Vercel, Netlify, Cloudflare Pages, etc.

## Usage

Templates are automatically fetched by the Liteshow API when syncing to user projects.

## Template Structure

Each template should include:
- `package.json` - Dependencies and scripts
- `src/` - Source code
- `public/` - Static assets
- `.env.example` - Environment variable template
- Configuration files (astro.config.mjs, tailwind.config.cjs, etc.)

## Contributing

To add or update templates:
1. Make changes to the template directory
2. Commit and push to main branch
3. Changes will be automatically picked up by the Liteshow API
